# Transfer Finder

Transfer Finder is a reverse articulation search platform that helps California Community College students start from a UC campus, UC major, or UC course requirement and find articulated equivalent courses.

## MVP Goal

Build a production-style MVP for reverse UC-to-CCC articulation lookup, starting with a focused dataset and clear source tracking.

## Planned Tech Stack

- Frontend: React, TypeScript, Vite, Tailwind CSS
- Backend: Python, FastAPI
- Database: PostgreSQL
- ORM and migrations: SQLAlchemy 2.0, Alembic
- Data pipeline: Python scripts
- DevOps: Docker Compose
- Testing later: pytest, Vitest, Playwright

## Current Status

Planning / skeleton phase. The repository currently contains project structure and documentation placeholders only.
